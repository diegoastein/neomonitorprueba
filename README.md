# NeoMonitor 🩺
### Simulador Neonatal de Alta Fidelidad Web-Based
**Desarrollado por el Dr. Diego Steinberg** *Médico Neonatólogo e Instructor de Reanimación Cardiopulmonar Neonatal*

---

## 🚀 Propuesta de Valor
**NeoMonitor** es una aplicación web diseñada para transformar la educación médica neonatal. Permite convertir cualquier par de dispositivos con conexión a internet en un ecosistema de simulación profesional (Monitor + Control Remoto) sin necesidad de instalar software adicional.

## ✨ Características Principales
* **Sincronización en Tiempo Real**: Control de parámetros vitales mediante Firebase Firestore.
* **Interfaz Multilingüe**: Disponible en Español, Inglés y Portugués para alcance global.
* **Fisiología Realista**: Ondas de ECG y pletismografía animadas que reaccionan a los cambios de frecuencia y saturación.
* **Sistema de Alarmas Inteligente**: Alarmas visuales y sonoras basadas en rangos clínicos de seguridad.
* **Herramienta de Debriefing**: Registro automático de eventos y cambios para análisis posterior a la simulación.

## 🛠 Guía de Conexión Rápida
1.  **Monitor**: Abre [neomonitor.pro](https://neomonitor.pro) en una Tablet o PC y selecciona "Usar como Monitor".
2.  **Control**: Escanea el código QR generado con un Smartphone para vincularlo como mando a distancia.
3.  **Simulación**: Ajusta los parámetros y observa la respuesta inmediata en la pantalla del monitor.

## 💻 Stack Tecnológico
* **Frontend**: React 18 & Tailwind CSS.
* **Backend**: Firebase (Auth & Firestore).
* **CI/CD**: Automatización de despliegues mediante GitHub Actions para entornos Beta y Producción.
